# Quickstart: Branding Pass

## Try it

```bash
flutter run
```

The app bar shows the Kristle header image instead of a plain title, and a placeholder
bar sits at the bottom of the screen, reserved for a future ad.

## Validate with tests

```bash
flutter test test/widget_test.dart
```

Validates: the header image is present in the app bar; the placeholder bar is present
at the bottom and has no tappable behavior.

See [spec.md](spec.md) for full acceptance scenarios.
